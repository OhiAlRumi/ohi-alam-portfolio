# Ohi Alam — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript for the SE235 portfolio assignment.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive layout, visual design, hover/focus states, and animations
- `script.js` — mobile navigation, scroll reveal, current year, and contact form handling
- `assets/Ohi_Alam_CV.pdf` — downloadable résumé

## Portfolio content

The portfolio presents Ohi Alam's Software Engineering studies, DIU Library Student Associate experience, DIU Library Mobile Application work, academic algorithm and statistics coursework, ESP32 library noise-monitoring concept, and developing interests in Blender, 3D modelling, animation, and game development.

Skill labels distinguish current project work, coursework, beginner learning, and future interests. Concepts and ongoing integrations are not presented as completed products.

## Run locally

1. Open this folder in Visual Studio Code.
2. Install/enable the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Test the navigation and contact form.

## Contact form setup

The form is configured for FormSubmit AJAX and currently points to `ohialam777@gmail.com`.

The first submission may trigger an activation email from FormSubmit. Open that email and activate the form, then submit a test message again. The website displays a success or error message through JavaScript. An internet connection is required.
